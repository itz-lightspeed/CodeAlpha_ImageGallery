# Responsive Image Gallery Website

A modern and fully responsive image gallery built using HTML, CSS, and JavaScript.
This project features category filtering, smooth hover animations, and an interactive lightbox system with next/previous image navigation.

## Features

* Responsive grid layout
* Category-based image filtering
* Smooth hover zoom effects
* Interactive lightbox preview
* Next and previous image navigation
* Dynamic filtering inside the lightbox
* Clean dark-themed modern UI
* Mobile responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Font Awesome Icons

## How It Works

### Filtering System

Each gallery card contains a category class such as:

* nature
* city
* art

When a filter button is clicked, JavaScript checks the selected category and displays only matching images while hiding the others.

### Lightbox Functionality

Clicking an image opens it inside a fullscreen lightbox overlay.
Users can:

* Close the lightbox
* Move to the next image
* Move to the previous image

The navigation system dynamically updates based on the currently active filter, meaning users only navigate through visible images instead of the entire gallery.

### Responsive Design

CSS Grid is used to create a flexible layout that automatically adjusts to different screen sizes, making the gallery fully responsive across desktop, tablet, and mobile devices.
